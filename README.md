# Smart Agricultural Market Price Analysis System

A web-based system for analyzing historical agricultural product
prices in Ethiopia (Maize, Wheat, Sorghum, Teff, Pasta, Livestock).

## Data Source
World Bank — Ethiopia Monthly Food Price Estimates.

## Stack
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQLite
- Node.js + Express
- React (Vite) + Recharts
